# 外部农机参考

这些模型只给资产工坊对照剪影和风格，不替换田里的农机。主进度仍用 `tractor_gen` 和各收获机占位。

## Kenney Car Kit — CC0

- `kenney-tractor.glb`
- `kenney-tractor-shovel.glb`
- `kenney-textures/colormap.png`

来源：https://kenney.nl/assets/car-kit

许可：CC0。GLB 里的贴图路径写成 `Textures/colormap.png`。文件放在 `kenney-textures/colormap.png`，工坊加载时把这条路径指过来。
