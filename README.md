# satellite-farm

武装城市的第一份可玩切片。和平建设和海上迎击发生在同一张棋盘上：9×9 城区，北侧相邻 9×9 海域，指挥中心在城区正中。岸线朝向是占位。

## 运行

需要 Godot 4。本切片在 Godot 4.7.2 下验证。

在仓库根目录：

```bash
godot --path .
```

无界面测试：

```bash
godot --headless --path . -s res://tests/slice_test.gd
godot --headless --path . -s res://tests/scene_smoke.gd
```

## 操作

棋盘是斜向俯视的占位像素，不是正上方的方格。先点单位、建筑或空地，再点动作或目标格。

点城区空地，只提供铺网格。那一格的网格完工以后，才出现能放进槽位的建筑。时间、整备、工班和迎击各自成组，还没到的阶段不显示。

和平按日推进，迎击按分钟推进。时间不会自己走，也没有倍速。点「结束本日」或按空格，才进入下一天。开局是和平 1月1日，先有五个和平日，第一波预警不会马上开始，也可以自己点「开始预警」。迎击里点「结束这一分钟」或按空格，敌方才执行这一分钟。`Esc` 取消当前动作。

地图由种子生成：海域和城区大约各一半，岸线、山地和礁石的形状随种子变化。山地不能铺网格。施工中的网格会整格变色。

滚轮、`-` 和 `=` 按整数倍缩放棋盘，一格设计像素画成 1×1 到 4×4 的方块，不模糊。窗口能放下的最大倍数是默认值；1280×800 下是 1 倍。

黄边是敌方下一步，红边是攻击格。炮台仍要手动指定目标，下令后立即结算。

数值、岸线朝向和爆破参数都是切片占位。清完尸骸不是胜利。
