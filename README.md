# satellite-farm

武装城市的第一份可玩切片。和平建设和海上迎击发生在同一张棋盘上：9×9 城区，北侧相邻 9×9 海域，指挥中心在城区正中。岸线朝向是占位。

## 运行

需要 Godot 4。本切片在 Godot 4.7.2 下验证。

在仓库根目录：

```bash
godot --path .
```

无界面测试：

```bash
godot --headless --path . -s res://tests/slice_test.gd
godot --headless --path . -s res://tests/scene_smoke.gd
```

## 操作

和平阶段可以暂停（`P`），也可以 1 倍或 2 倍。先铺网格再放建筑。轻质网格只有一个槽；升降网格可以同时放和平建筑和炮台，并且是机体部署口。

预警结束，或提前迎击后，敌人从海域出现并进入回合。黄框是敌方下一步，红框是攻击格。炮台要手动指定目标，下令后立即结算。`空格`结束回合，`Esc`取消当前工具。

数值、岸线朝向和爆破参数都是切片占位。清完尸骸不是胜利。
