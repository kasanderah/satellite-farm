# 环穗 Maya 资产交付

可玩页用 Three.js（r186）画建筑和农机。这份说明只写现在这条管线真正会读的约定。目录占地、门朝向和格子都对着 `src/build/catalog.js`、`src/modulus.js`、`src/build/meshes.js`。

## 1. 交什么

每个建筑或农机一个目录，文件名用小写和短横线：

| 文件 | 必须 | 说明 |
| --- | --- | --- |
| `bld_<id>_lod0.glb` 或 `rig_<id>_lod0.glb` | 是 | 游戏里用的模型。glTF 2.0 二进制，贴图打进文件 |
| `bld_<id>_lod0.fbx` | 否 | 只作存档。游戏不直接读 FBX |
| `bld_<id>_source.ma` | 否 | Maya 工程。给改模的人，不进包 |
| `thumb.png` | 否 | 菜单缩略图。没有时游戏用程序剪影 |

`<id>` 和目录里的 id 一致，例如车库是 `garage`，所以文件是 `bld_garage_lod0.glb`。

LOD 现在不是硬性要求。要交的话：

- `lod0`：玩家贴着看的样子
- `lod1`：三角面大约是 lod0 的一半，镜头远于约 80 m 时换
- `lod2`：只留外轮廓，镜头远于约 400 m 时换

不要交 Maya 的 `.mb` 当运行文件。运行文件只认 glb。

## 2. 单位、原点和轴

- 1 个 Maya 单位 = 1 米。导出前把场景单位设成米，缩放冻结成 1。
- 右手系，Y 朝上。Three.js 也是 Y 朝上，不要交 Z 朝上的文件。
- 原点在占地中心，落在地面上（Y = 0）。模型往上长，不要把整栋楼的中心放在原点，否则放下去会有一半埋进地里。
- 建筑的门、车库进出车子的那一面，朝本地 **-Z**。游戏里 `roadFaces: ['s']` 就是这一面。绕 Y 转 90° 一档之后，箭头跟着这面走。
- 农机车头朝本地 **+X**，轮子贴着 Y = 0。这和现在田里车的车头一致。
- 导出时勾上「Y 朝上」。不要在 glb 里再包一层非 1 的缩放，也不要留未冻结的旋转。

格子是 4.2 m（`modulus.js` 的 `CELL`）。目录里的 `w`、`h` 是占地格数，不是模型外包盒。模型可以比占地伸出一点点檐口，但碰撞和挡路只认这 `w × h` 格。不要在模型里再做一套碰撞体交上来。

## 3. 材质

游戏网格是 `MeshStandardMaterial`。一个材质对应一张或一组贴图，不要用 Maya 的图层着色器、曲面着色器或自定义 Arnold 节点当最终结果。

| 贴图 | 色彩空间 | 命名 |
| --- | --- | --- |
| 底色 | sRGB | `bld_<id>_basecolor.png` |
| 粗糙度 / 金属度 | 线性。glTF 把金属度放 B、粗糙度放 G | `bld_<id>_orm.png` |
| 自发光 | sRGB。只给灯、屏幕 | `bld_<id>_emissive.png` |
| 法线 | 线性，OpenGL 朝向（Y 朝上） | `bld_<id>_normal.png`，可选 |

材质命名：

- `M_metal` 金属壳
- `M_dark` 深色结构
- `M_glass` 玻璃
- `M_lamp` 灯。要自发光，不要靠把底色调得很亮

玻璃不要交折射网络。粗糙度大约 0.15，金属度大约 0.6，透明度交给游戏。灯的自发光强度游戏会再乘，贴图里保持 0–1。

贴图边长用 2 的幂，建筑 lod0 不超过 1024，农机不超过 512。不要交 4K。

## 4. 命名和层级

- 网格：`bld_<id>_<部位>`，例如 `bld_garage_shell`、`bld_garage_door`。
- 空组只留一个根：`bld_<id>`。根下面不要再套「过去的版本」「参考」这类组。
- 门或进出面的网格名里带 `door`，方便以后单独开门。现在的占位车库还不会播门动画，但名字先按这个留。
- 不要把灯光、摄像机、骨架、历史曲线导出进 glb。农机如果没有蒙皮，不要留关节。

## 5. 导出清单

从 Maya 交一版之前对一下：

1. 单位是米，冻结变换之后缩放是 1、旋转是 0，只有根可以有平移到原点。
2. 地面在 Y = 0，门朝 -Z，占地中心在原点。
3. 导出 glb，Y 朝上，贴图嵌进文件，三角面，没有曲线和非流形。
4. 用 Windows 的 glTF 查看器或直接丢进资产工坊看一眼：门要在近处那一侧（对着 -Z），没有埋到地里，没有放大一百倍。
5. 在 `src/build/catalog.js` 写上 id、占地格、施工日、造价、板材、`roadFaces`。游戏不从模型里猜占地。
6. 把 glb 放到 `refs/buildings/<id>/`（农机放到 `refs/machines/<id>/`）。可玩页还在用 `src/build/meshes.js` 里的程序块。换上交来的 glb 时，只替换对应 id 的网格，不要改格子和门的方向。

施工日、造价、板材、车位是建筑属性，写在目录里，不写进模型。没完工的车库不能买车，也不能把车开回去。
