# 框架 B · 田地最小闭环

这一刀换成整块作业。田上不保存半幅蒙版，进行中的幅宽、起点和进度只放在当前工单上。做完才整块换样子。

## 两条平行的阶段

点一块田，可以 **整地**，也可以 **种植**。

整地只有硬作业，没有时间窗。这一季的配方叫 **清地**，目标地面是 **一般田地**。配方里一道作业：**犁地**，能力 **犁田**。犁完，地面变成一般田地。

种植从 **播种** 开始。播种做完，生长钟才走。作物自己声明能种在哪些地面上。拉斯提卡要一般田地。收拾做完回到一般田地，下一次不用再整地。

## 拉斯提卡

播种 → 成熟 → 收割 → 收拾。

播种、收割、收拾是硬作业。成熟是播种完成之后的生长时间，不是农机作业。这一刀没有软作业。硬作业锁住整块田，做完才解锁。

## 作业

每道作业有稳定 id 和中文名，硬或软，需要的能力（中文名就是能力键），以及做完后的田面，或者「不影响」。作业发出事件，田块单元改样子。阶段图决定下一步，作业本身不改阶段。

## 农机

类别：自走机、拖挂、飞行机。这一刀只有一台自走一体机 **万能农机**，能力是犁田、播种、收割、收拾。它有作业起点、左右对称的总幅宽、1× 下的作业速度（米/秒）和转移速度。自走机有功率输出、能源（现在只做电）和能量。拖挂只留功率需求的占位，这一刀不出挂具、不管联合覆盖顺序。

机库车位以后再做。现在这一台从中枢机库开出来。

## 调度

事件排队。能独立完成的自走机里，选幅宽乘速度更高的那台。田块只从当前工单读幅宽、起点和进度。

## 地块编号

中枢地块是 **C0**。田块 **P(x,y)**：东是 +X，北是 +Y。环面上东沿环的 +X，北取跨环的 +Z。买地界面以后再做。

## 这一刀不做

买地、软作业、挂具和模块、飞行机、半幅蒙版、旧的商品薯甘特、工坊农机编辑器接到田上、120 日的细调。
