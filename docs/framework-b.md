# 框架 B · 拉斯提卡

整地和种植是两条平级的链。种植阶段、软窗、田面色和生长钟只读阶段编辑器编译结果；没有工坊档时读仓库 `data/field-stages/lastika.json`。不读商品薯甘特。

## 整地

点一块田可以整地。这一季的配方是 **清地**，目标地面是 **一般田地**。一道硬作业：**犁地**，能力 **犁田**。犁完，地面变成一般田地。整地没有时间窗，也不写进种植链的 O→A。

## 种植

拉斯提卡要种在一般田地上。作物阶段是一张图，写在 `lastika.json` 的 `graph`。整地不在这张图里。播种是从图外进入头阶段的硬作业。

边上只有两种。`hard`：人在这一阶段里开工的硬作业做完，才进入下一阶段。`natural`：这一阶段的世界日走完，而且那道硬作业还没开工，才进入下一阶段。

头阶段是生长，没有上一作物阶段。到点自然进入成熟。成熟不是尾：它有收获窗，窗内收割走硬边到收后；没人开工就自然进入腐烂。腐烂是尽头，没有后继。收后没有时长，收拾没做完就一直停着。收拾走硬边，进入可再种尾。尾没有后继，也没有时长。

生长时长是阶段 B 的世界日。1× 下一世界日 = 12 现实分钟（720 现实秒）。B 的 36 世界日约 432 现实分钟。成熟窗是图里的 8 世界日。软窗 from/to 仍是世界日，挂在生长上，不改阶段。

软作业的 `look` 仍是「不影响」。跟车刷色是 `brush`，硬作业和软作业都默认关。关着的时候，软作业做完不把成熟色写进田面。硬作业做完仍按自己的阶段样子定稿。趟数仍按田宽除以幅宽。

田面色来自同一份文档：未整地用 O 的土色，幼苗和成熟用植株的 `young` / `ripe`，残茬用 `stub`。一般田地是犁地后的深土。

## 农机

自走机、拖挂、飞行机。飞行只留类别，不起飞。

自走一体机 **万能农机**：犁田、播种、收割、收拾、追肥、培土。拖拉机本身没有作业能力，犁挂上去才有犁田。一体机是机体自己盖住全部所需能力，不是写死的机型名。

## 调度

每块田的队列里只有这一条链的下一道可派作业。硬作业按阶段顺序。软作业在窗口内可派，过期的软作业不挡住硬作业。

每一轮把这些下一刀和空闲的自走机（含已经挂上的拖挂）配在一起。能做的机器更少的先派。同样紧时，更早进队列的先派。机器里，机体盖住全部所需能力的优先于挂具组合；然后看幅宽乘作业速度；再看路程除以巡航。一台机器同时只接一单。

浮标和信息框名称旁的短状态跟着工单走：等待整地、犁地中、等待播种、播种中，以及追肥、培土、收割、收拾。没有工单时，浮标写地面或阶段名，不写长说明。

## 工坊

资产工坊 **田间 → 阶段编辑器** 默认打开拉斯提卡。保存钥匙仍是 `ringsheaf.assetlab.fieldStages.v1`，作物槽是 `lastika`。可玩页刷新或点「重读工坊」后换上。序列组 O、A、B、D、E 必有，C 和中间段可加减。阶段名和 id 可改。色条上下序是执行顺序。

## 这一刀不做

买地、把整地塞回商品薯日历、飞行、半幅蒙版、残茬外观表、底部信息框重排。
